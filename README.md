# LunAI Dissertation Digital Artefacts

This repository contains the supporting digital artefacts for my final-year BSc (Hons) Computer Science dissertation:

**LunAI: Physiology-Aware Fitness Coach with Integrated Database System**

The main LunAI prototype/source code is stored separately. This repository acts as a digital appendix containing supporting evidence, datasets, diagrams, testing materials, prototype files, and generated figures referenced in the dissertation.

## Repository Structure

### AI-model-training
Contains materials related to the trained recommendation component used in LunAI, including synthetic training data, response banks, model-training scripts, trained model files, and training outputs such as the loss graph.

### Dissertation-figures
Contains screenshots and figures used within the dissertation, including interface outputs, dashboard screenshots, pose-tracking examples, API evidence, and database evidence.

### Early-prototypes
Contains early prototype files used during development, including earlier Python/MediaPipe pose-tracking experiments and notebook-based testing.

### System-design
Contains system design artefacts, including the architecture flow and database/entity relationship design materials.

### Testing-evidence
Contains supporting evidence for system testing, including backend/database testing scripts and any related validation outputs.

### diagrams-charts
Contains generated diagrams and charts used to support the dissertation, including visualisations related to performance, training, system architecture, and evaluation.

## Purpose

These artefacts provide supporting evidence for the development, implementation, testing, and evaluation of LunAI. They are intended to accompany the written dissertation and demonstrate the process behind the system design, AI recommendation component, testing results, and visual outputs.

## Notes

The main working LunAI software prototype is provided in a separate GitHub repository. This digital appendix is not intended to run the full application, but to document and evidence the supporting artefacts used throughout the dissertation.
